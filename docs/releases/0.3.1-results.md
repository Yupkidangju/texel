# 0.3.1 공개 배포 결과

작성: 2026-10-16 (Asia/Seoul). 기준: [계획](0.3.1-plan.md). 공개 저장소·커밋/푸시·태그 자동 릴리스 및 공개 자산 재다운로드 검증을 완료했다.

로컬 코드: 0.3.1, MCP39도구/89함수, Apache-2.0. 공통 wheel/sdist와 Windows x64 portable 배포. Python 3.14+ 설치가 다른 OS/CPU의 실행 전제다. 원본 감사/과거 배포물은 보존한다.

## 로컬 검증

- 전체 **304 passed / 190.80초**, Ruff check PASS / format **73 files already formatted**. evidence_0_3_1/local_full.log, ruff_check.log, ruff_format.log.
- 태그/제품·패키지 버전/저작권 및 portable ZIP 이름·소스 변조 회귀 5개 추가. 처음의 새 모듈 수집 실패는 개별 기능 실패 증거로 확대하지 않는다.
- wheel/sdist에 LICENSE/NOTICE 원문 및 Apache-2.0 메타데이터 포함, wheel 제품 소스 동일성, 별도 설치본 0.3.1의 CLI/80×24 UI/MCP stdio39·함수89·batch/undo 검사 통과. local_wheel_check_final.log 및 local_wheel_result.json.

- 공식 action SHA 고정, actionlint1.7.12 워크플로 검사 통과. 공개 후보 파일의 자격증명 패턴 검사에서 발견 없음. 이 검사는 모든 비밀정보 부재의 증명이 아니다.
- uv 대체 설치의 캐시도 프로젝트 .cache/uv로 한정했고 배포 회귀5개와 격리 wheel 검사를 다시 통과했다(local_wheel_cache_scoped.log).
- 로컬 portable 사전 빌드 output/Texel-0.3.1-win64-20261016-140238는 자체 Python CLI/UI/MCP 검사를 통과하고 제품37+LICENSE/NOTICE의 39파일이 ZIP과 일치한다. local_portable_build.log, local_portable_check.log, local_portable_result.json. 이것은 GitHub CI에서 별도로 빌드한 공개 자산과 구분한다.

아래는 초기 CI 실패·수정과 최종 성공을 구분한 기록이다.

최초 호스팅 CI 38853333878은 새 checkout에 .cache 부모가 없는 상태에서 pytest --basetemp .cache/pytest-ci가 mkdir(parents=False)를 호출해 실패했다. Linux3.14 로그는 127 passed/177 fixture errors이며 제품 동작 실패와 구분한다. 로컬에서는 기존 .cache가 있어 드러나지 않았다. CI 초기 단계에서 작업 디렉터리를 명시적으로 생성하고 새 커밋으로 7환경 전체를 다시 검증한다. 실패 로그는 ci_initial_linux14.log에 보존한다.

Windows ARM64의 cryptography50.0.2 설치는 OpenSSL 개발 환경 부재로 실패했다(ci_initial_windows_arm.log). 공식 PyPI에는 win_amd64만 있고 win_arm64 wheel은 없다. 계획의 최초 네이티브 가정을 명시적으로 보정하여 Windows11 ARM64는 x64 Python 에뮬레이션으로 검증한다. Linux/macOS ARM64 네이티브 지원은 유지한다. Windows ARM64 네이티브 바이너리/개발 도구 설치를 제공한다고 주장하지 않는다.

## 공개 릴리스 및 다운로드 검증

[공개 저장소](https://github.com/Yupkidangju/texel), 기본 main, GitHub 라이선스 인식 Apache-2.0. Copyright 2026 yupkidangju@gmail.com을 LICENSE/NOTICE/패키지에 포함했다. [v0.3.1](https://github.com/Yupkidangju/texel/releases/tag/v0.3.1)은 **2026-10-16 14:20:16 KST**에 공개했으며 draft/prerelease가 아니다. 외부 PyPI 게시는 수행하지 않았다.

- 태그 CI도 **7환경 각각 304 passed, 0 skipped/errors/failures**. tag_ci_results.json.
- GitHub Windows portable 빌드는 자체 Python3.15로 **304 passed / 138.34초**, Ruff73파일, CLI/UI/MCP 및 제품37+라이선스2파일의 checkout↔폴더↔ZIP 검증 통과. portable_ci.log, portable_ci_result.json, release_jobs.json.
- 공개 자산4개를 output/github-release-v0.3.1/에 다운로드했다. SHA256SUMS의3개 배포 파일을 실제 bytes 및 GitHub asset digest와 대조해 모두 일치했다. published_release.json, published_roundtrip.json.
- 다운로드한 wheel/sdist/portable의 **제품 Python37개는 모두 Git 태그 bytes와 일치**한다. LICENSE도 일치한다. portable NOTICE만 Windows CRLF/Git LF 차이가 있으며 개행 정규화 후 내용은 정확히 같다. 이를 모든 파일의 무조건적인 byte 동일성으로 보고하지 않는다.
